# Sales Performance Dashboard

## Project Overview
This project analyzes the Sample Superstore dataset using SQL and Power BI to identify key sales and profit trends.

## Tools Used
- Power BI
- MySQL
- Microsoft Excel

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Average Discount KPI
- Sales by Category
- Profit by Category
- Sales by Region
- Sales by Segment
- Top 10 Sales by State
- Profit by Sub-Category

## Interactive Filters
- Region
- Segment
- Category

## Key Insights
- Technology generated the highest sales and profit.
- The West region contributed the highest sales.
- Copiers were the most profitable sub-category.
- Tables recorded the highest loss.
